# Pixora - AI генератор названий, логотипов и брендбуков для бизнеса

Современное веб-приложение для генерации полного брендинга с использованием искусственного интеллекта.

## 🚀 Возможности

### 1. Генерация названий

- **ИИ-генерация** через GenAPI, модель gpt-5-6-luna
- **Персонализация** по нише, стилю и письменности
- **Шесть вариантов** за один запрос, каждый — своим приёмом нейминга

### 2. Создание логотипов

- **dalle-3** рисует знак, название набирается шрифтом на сервере
- **Адаптация** под название и сферу деятельности
- **Вектор после оплаты**: SVG, прозрачный PNG 2048 px и кадр модели

### 3. Генерация брендбуков

- **PDF на 15 полос**: о бренде, логотип и его блокировки, охранное поле, недопустимое
  использование, палитра с настоящим контрастом по WCAG, типографика, набор текста,
  иконки и графика, носители, выходные данные
- **Логотип в семи версиях**: три блокировки и три цветовые, вектором и растром
- **Палитра от самого логотипа** — цвета берутся из знака, а не угадываются
- **Шрифты с лицензией OFL** — их можно ставить сотрудникам и использовать коммерчески
- **Носители в рабочих размерах**: визитка с вылетами под нож, пост, сторис, обложка
  сообщества, презентация, подпись письма
- **Предпросмотр** перед покупкой, **один архив** после оплаты
- **Личный кабинет** для управления брендбуками

## 📱 Пользовательский путь

### Шаг 1: Генерация названия

1. Перейдите на главную страницу
2. Заполните форму генерации названий:
  - Ниша бизнеса
  - Ключевые слова  
  - Стиль названий
3. Выберите понравившееся название

### Шаг 2: Создание логотипа

1. Автоматический переход на страницу генерации логотипа
2. Нажмите "Сгенерировать логотип"
3. Дождитесь создания логотипа (30-60 секунд)

### Шаг 3: Создание брендбука

1. Переход на страницу генерации брендбука
2. Нажмите "Создать брендбук"
3. Просмотрите предварительный брендбук: слоган и версии логотипа
4. Оплатите заказ
5. Дождитесь сборки — ход виден на странице, занимает несколько минут
6. Скачайте всё одним архивом; ссылка на него придёт и письмом

### Шаг 4: Управление

- Просматривайте все созданные брендбуки в личном кабинете
- Скачивайте оплаченные брендбуки
- Создавайте новые проекты
