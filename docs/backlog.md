# развитие

- поправить материалы для соцсетей/визитки/презентации и тд 
- поле с текстом для запроса ии что изменить в логотипе и тд
- перед генерацией лого - отдельная дешевая модель собирает инфу о названии и всех ключевых словах и доп информации - и генерирует собственный промпт с собственной идеей для лого - для генерации специализированного лого для конкретного названия - каждый раз при повторе генерации лого - промпт обновляется, модель промпта придумывает новый логотип
- Перегенерация блока (палитра / иконки / слоган) за 1 попытку квоты — превращает разовую покупку в работу с продуктом. - имеется в виду дать возможность поработать с брендбуком или перегенерировать с пожеланиями через ии - чтобы пользователь не получал строго тот результат который дает иишка и сервис а он мог изменить что то под себя 
- Русская специфика, за которую платят: шаблоны карточки WB/Ozon, оформление ВК/Telegram/Авито, визитка под типографию в CMYK, подсказка проверить название в ФИПС и свободный домен .ru. Это то, чего нет у зарубежных looka/brandmark.
- Лицензия покупателю в архиве: кому принадлежит логотип, что можно регистрировать как ТЗ, лицензии шрифтов и иконок. Для B2C-покупателя это снимает главный страх.
